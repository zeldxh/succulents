# succulents

crud web app for managing succulents. built with spring boot, thymeleaf, bootstrap, jpa/hibernate, and mysql. class exercise.

## run

1. run `src/main/resources/practica.sql` in mysql to create the `practica` database, the `usuario_practica` user, the `suculenta` table, and some sample data.

2. copy the env file and set your credentials:

   ```sh
   cp .env.example .env
   ```

3. open the project and run it.

4. go to http://localhost:91
